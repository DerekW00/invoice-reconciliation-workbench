# Data provenance

All CSV fixtures, organization/vendor names, invoice/PO/receipt identifiers, reviewer notes and provider responses were newly synthesized for this repository on 2026-10-26. They do not represent customers, business transactions or former-employer formats. No prior application source or domain schemas were read or translated.

fixtures/demo contains three small source CSVs and fixtures/expected.json freezes independently checked exception outcomes. fixtures/provider contains normal, malformed, invalid-reference and failed-provider scripted responses. The evaluator rolls its own database writes back.

Third-party runtime asset: HTMX 2.0.8, downloaded from the versioned htmx.org package distribution. static/vendor/HTMX-LICENSE preserves its Zero-Clause BSD license. No remote font, icon, image or application asset is used. Dependency licenses remain with the pinned upstream packages.
